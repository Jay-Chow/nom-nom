# Nom-Nom Project

Welcome to the **Nom-Nom** project! This application is designed to help you create and manage recipes with ease. Below, you'll find all the necessary details to get started with the project.

---

## 🚀 Getting Started

### Prerequisites
Ensure you have the following installed on your system:

- **Java 17** or higher
- **Maven 3.8+**
- **Spring Boot 2.7+**

### Clone the Repository
```bash
# Clone the repository to your local machine
git clone https://github.com/your-repo/nom-nom.git
cd nom-nom
```

---

## 🛠️ How to Run the Project

### Using Maven
1. Navigate to the project directory:
   ```bash
   cd nom-nom
   ```
2. Run the application:
   ```bash
   ./mvnw spring-boot:run
   ```

### Using the JAR File
1. Build the project:
   ```bash
   ./mvnw clean package
   ```
2. Run the JAR file:
   ```bash
   java -jar target/nom-nom-0.0.1-SNAPSHOT.jar
   ```
